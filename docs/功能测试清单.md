## 四、视觉识别（手册第 2 章）

**模板匹配识别**（find_object_2d）：
```bash
roslaunch find_object_2d find_object_2d.launch
rosrun robot_slam find_object.py
```

> ⚠️ **目录名 ≠ 包名**：包在 `src/abot_find/` 目录下，但 `package.xml` 里写的是
> `<name>find_object_2d</name>`。roslaunch 的第一个参数按**包名**解析，
> 所以不能用 `roslaunch abot_find ...`（会报
> `RLException: ... is neither a launch file in package ... nor is ... a launch file name`）。

> ⚠️ `robot_slam/scripts/find_object.py` **有 bug 跑不起来**：`find_cb` 被嵌套定义在
> `__init__` 内部，`rospy.Subscriber(..., self.find_cb)` 会抛 `AttributeError`。
> 测试前先把 `find_cb` 反缩进成类方法。

**二维码识别**（ar_track_alvar，在 `ar_track_alvar-noetic-devel/ar_track_alvar/`）：
```bash
roslaunch ar_track_alvar pr2_indiv.launch      # 注意：这是 PR2 示例参数，需按本机改
```

**OpenCV 示例**（30 个 launch）：
```bash
roslaunch opencv_demo threshold.launch
roslaunch opencv_demo edge_detection.launch
roslaunch opencv_demo hough_lines.launch
roslaunch opencv_demo hsv_color_filter.launch
rosrun opencv_demo hsv.py                      # 本包唯一的自写脚本
```

> ⚠️ opencv_demo 的 launch 依赖系统包 `opencv_apps`，没装会报错。
