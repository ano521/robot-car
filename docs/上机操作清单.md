## 第 4 步 · 查相机（B1）—— ✅ 已出图（2026-10-12 17:50），剩"拍到哪"未确认

> **✅ 2026-10-12 17:0x 真因：`usb_cam2` 一启动就死，`/usb_cam2/image_raw` 压根没人发。**
> 不是"话题配错"，是**那个话题不存在**。

第 4 个标签页（`multi_yolo`）的日志：

```
[INFO]  Starting 'head_camera' (/dev/video2) at 640x480 via mmap (yuyv) at 30 FPS
[ERROR] VIDIOC_STREAMON error 5, Input/output error
[usb_cam2-2] process has died [exit code 1]
```

**第一版假设（❌ 已推翻）：这台相机给不了 30 fps，而 `usb_cam` 的 `framerate` 默认是 30。**
`v4l2-ctl -d /dev/video2 --list-formats-ext` 实测：

| 格式 | 1280×720 | **640×480** |
|---|---|---|
| MJPG | 30 fps | **25 fps** |
| YUYV | 10 fps | **25 fps** |

**640×480 下两种格式都只到 25 fps，没有 30 的选项。**

> **❌ 但加了 `framerate=25` 并没有修好（17:35 实测）**：日志确实变成 `at 25 FPS` 了，
> 下一行**照样** `VIDIOC_STREAMON error 5`。**参数生效、故障不变 ⇒ 帧率不是元凶。**

**（A）⭐ 已做过的决定性取证 —— 设备本身也开不了流（17:5x）**

```
v4l2-ctl -d 2 --stream-mmap --stream-count=10

```
