## 动手之前

**改动边界（不要越线）**

| 可以改 | 不可以改 |
|---|---|
| U 盘工程 `/media/abot/999/abot`（＝ Windows 的 `E:\abot`） | 车内 `/etc`（含 `udev/rules.d`） |
|  | 车内 `/home/abot/*`（含 `.bashrc`） |

⚠️ **不要在 `/home/abot` 下建软链接**指向 U 盘工作区 —— 那属于车内。

**环境事实（每次上机都要能背出来）**

| 项 | 值 |
|---|---|
| 工程位置 | `/media/abot/999/abot` —— **不是** `/home/abot/abot`（不存在） |
| 底盘串口 | `/dev/abot_driver` → `ttyUSB1` |
| 雷达串口 | `/dev/rplidar` → `ttyUSB0` |
| 相机 | 两台：`HD USB Camera` = `video0`/`video1`；`Integrated Webcam_HD` = `video2`/`video3`<br>（每台出两个节点，第二个是元数据通道，真正可用的是 `video0` 和 `video2`） |
| 登录 | `abot@abot` |

⚠️ **udev 别名认的是 USB 插口的物理位置。调试期间不要换插口**，换了两台串口设备会对调。

**收工时永远记得**：改动要 **U 盘和 D 盘仓库两边都落**（`E:\abot` ↔ `D:\Program Files\robot car\abot`）。
上次就出现过 U 盘改了、仓库没跟上的情况。

**目的**：C3"雷达起不来"的根因是残留 `rplidarNode` 占着 `/dev/ttyUSB0`，
而旧版 `killall.sh` 杀不干净。新版必须证明有效，否则后面每一步都不可信。

```bash

sleep 15
./killall.sh
```

**两条都必须无输出**：

```bash
pgrep -a -f rplidar
pgrep -a -f roslaunch
```

**不对怎么办**：回到手工三连（已实测有效）：

```bash
pkill -9 -f roslaunch
pkill -9 -f rosrun
pkill -9 -f /opt/ros/noetic/lib
```

然后把漏网的那类进程补进 `killall.sh`（U 盘可改）。

## 第 4 步 · 查相机（B1）

```bash
rostopic list | grep -iE "image|cam"
v4l2-ctl --list-devices
fuser /dev/video0 /dev/video2 2>&1      # 看有没有别的进程占着
```

**判断**：

- 话题表里有 `/usb_cam/image_raw` → 相机起来了，是 RViz 里 `Image Topic` 配错
- 完全没有 → `usb_cam` 节点没起来，或被别的进程占着

**必须做的一件事**：**实拍确认哪台相机拍得到桌面 / 机械臂前方**
（`cam_track` 用 `video0`、`yolov8_ros` 用 `video2`，指的是两台不同的相机，
代码本身没写错；但要确认这两台各自是不是该干这个活）。

## 第 5 步 · 建自己房间的地图（C4）

**前提**：第 2 步已通过（串口干净）。

**现状问题**：现在用的是厂商地图，能定位但**不准**（RViz 里激光点不贴墙），
路径规划结果不可信 —— 必须给自己房间重新建图。

```bash
./killall.sh
./1-gmapping.sh
```

**操作顺序**：

1. 清空地面，机器人周围 2 m 内别放东西；手放在电源开关旁
2. 切到**最后一个标签页**（键盘遥控）
3. **先抬起机器人**（轮子离地空转），按 `i` 看轮子是否往前转、`k` 停 —— 确认方向对
4. 放下机器人，慢速绕房间走一圈（先贴边走，再走中间），转角要慢
5. 回到起点后保存 —— **必须用绝对路径 `-f`**，这样生成的 yaml 里 `image:` 才是绝对路径：

   ```bash
   rosrun map_server map_saver -f /media/abot/999/abot/src/robot_slam/maps/my_home
   ```

   > 名字用 `my_home`，避免和厂商地图 `abot/maps/my_room.*` 混淆。

6. 收工 `./killall.sh`

**键盘对照**（`teleop_twist_keyboard`）：

```
   u    i    o
   j    k    l
   m    ,    .
```

`i` 前进 · `,` 后退 · `j` 左转 · `l` 右转 · `k` 停 · `q`/`z` 调速

**不用折腾的两件事**（已核实）：

- `view_gmapping.rviz` 已配好：Fixed Frame = `map`，LaserScan = `/scan_filtered`，Map = `/map`，**不用手动打勾**
- `gmapping.launch.xml` 里 `xmin/ymin/xmax/ymax` 只有 ±1.0 m 方框，**不用改** ——
  那只是初始尺寸，gmapping 会自己扩图（厂商地图是 14.7 m × 14.7 m）

**收尾**：回到 Windows 后把 `my_home.{pgm,yaml}` 同步到 D 盘仓库。
