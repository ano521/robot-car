## 一、手册在哪、怎么看

| | 位置 |
|---|---|
| 原文件 | `C:\Users\lenovo\Downloads\移动抓取机器人.pdf` |
| 渲染好的页面图 | `D:\robot-car-backup\robot-car-ref\pages\pNNN.png`（148 页，104 MB） |
| 渲染脚本 | `D:\robot-car-backup\robot-car-ref\render.ps1`（备用，改页数用） |

**为什么必须先渲染**：这份 PDF 用了缺 ToUnicode 映射的嵌入字体，中文**完全无法抽取**
（`pdftotext` 抽出 0 个汉字，只剩数字和标点），所以只能渲染成图来读。

渲染脚本用 Windows 自带的 WinRT PDF API，不需要装 poppler 或 pymupdf。
用法（改 `FIRST`/`LAST` 即可）：

```bash
cd /d/robot-car-backup/robot-car-ref
PDF_PATH='D:\robot-car-backup\robot-car-ref\src.pdf' \
OUT_DIR='D:\robot-car-backup\robot-car-ref\pages' \
FIRST=1 LAST=10 WIDTH=1240 \
powershell.exe -NoProfile -Command '$c=[Console]::In.ReadToEnd(); Invoke-Expression $c' < render.ps1
```

> 注意：`-Command -` 是逐行执行 stdin 的，会被多行 `for` 循环拆散，必须用
> `[Console]::In.ReadToEnd()` 整份读入再 `Invoke-Expression`。
> 另外本机 PowerShell 执行策略是 Restricted，不要用 `-File` 直接跑脚本。

## 四、手册与仓库已知不一致的地方

**手册里的命令不能照抄**，至少有这三处：

1. **工作区路径不同**
   手册用的是 `~/abot_ws/src/...`，本仓库是 `~/abot/src/...`。
   手册第 2 章的 `cd abot_ws/src/robot_slam/scripts/` 要改成 `cd ~/abot/src/robot_slam/scripts/`。

2. **包名不同**
   手册第 24 章写 `rosrun yolo_detection arm_move.py 机械臂归零`，
   仓库里的包叫 `yolov8_ros`，且 `arm_move.py` 在 `yolov8_ros/script/`
   和 `vl_locate/scripts/` 各有一份。

3. **手册让你手写脚本，仓库里不一定有**
   手册第 2、3 章要求在 `robot_slam/scripts/` 下新建 `find_object.py`、
   `ar_tracker_move.py`。其中 `find_object.py` **已存在**，`ar_tracker_move.py` **没有**。

## 五、对照手册核对时发现的代码问题

- `abot/src/robot_slam/scripts/.py` — **文件名损坏**，只剩扩展名。内容是
  LaserScan 订阅脚本，应重命名。
- `abot/src/robot_slam/scripts/find_object.py` — `find_cb` 方法被**嵌套定义在
  `__init__` 内部**，导致上一行的 `rospy.Subscriber(..., self.find_cb)` 会直接
  抛 `AttributeError`（方法尚未存在于类上）。需要把 `find_cb` 反缩进成类方法。
